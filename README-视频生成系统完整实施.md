## 📖 使用文档

### 管理员

**配置API密钥**:
- 访问: `/admin/settings/video-generation-config`
- 配置火山引擎、即梦、可灵API密钥
- 配置文生图和图生视频的所有参数
- 保存

**配置套餐权限**:
- 访问: `/admin/packages`
- 编辑每个套餐
- 配置视频生成权限（配额、质量、分辨率等）
- 保存

### 用户

**免费用户**:
- 点击"生成视频" → 提示升级

**付费用户**:
- 点击"生成视频" → 配置参数 → 开始生成
- 根据套餐，可用功能不同
