# 用户专属邀请码推荐系统设计

## 🎯 系统概述

91Writing 采用用户专属邀请码推荐系统，每个用户都有唯一的邀请码，通过邀请朋友注册获得奖励，实现用户增长和社交传播。

## 📋 核心特性
### ✅ 已实现功能
- 🎟️ **用户专属邀请码**：每个用户注册时自动生成6位邀请码
- 👥 **邀请关系追踪**：完整记录邀请者和被邀请者关系
- 🎁 **自动奖励发放**：邀请成功自动获得奖励
- 📊 **统计功能**：邀请人数、奖励记录、邀请列表等
- 🔗 **分享链接**：自动生成带邀请码的注册链接

### 🚀 使用场景
- 用户推荐朋友注册获得奖励
- 社交网络病毒式传播
- 用户自发增长机制
- 推荐奖励计划

**数据结构**：
```sql
users:
- invite_code: 用户专属邀请码
- invited_by: 邀请者ID

user_invites:
- inviter_id: 邀请者ID
- invitee_id: 被邀请者ID
- reward_status: 奖励状态
- created_at: 邀请时间

invite_rewards:
- user_id: 获得奖励的用户
- invite_id: 邀请记录ID
- reward_type: 奖励类型（积分/套餐/现金）
- amount: 奖励数量
```

## 🎯 推荐实现方案

### 方案A：双轨制（推荐）
同时支持两种邀请码机制：
1. **管理员激活码**：用于官方营销活动
2. **用户邀请码**：用于用户推荐系统

### 方案B：纯用户邀请码
专注于用户推荐系统，取消管理员激活码

### 方案C：统一邀请码系统
将两种机制合并为一个统一的邀请码系统

## 📊 业务价值分析

### 管理员激活码
