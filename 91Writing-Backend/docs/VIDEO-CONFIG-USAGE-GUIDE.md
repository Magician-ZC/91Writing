## 🔍 火山引擎3个密钥的区别

### 为什么需要3个密钥？

火山引擎有两套认证系统：

**系统1：通用SDK认证（Access Key系统）**
- Access Key ID：公开的身份标识
- Secret Access Key：私密的签名密钥
- 用途：通用服务（语音、视觉、视频等）
- 认证方式：HMAC签名

**系统2：文生图专用认证（API Key系统）**
- 文生图 API Key：独立的API密钥
- 用途：专门用于文生图服务
- 认证方式：直接Header认证
- **更简单，推荐使用** ✅

### 获取密钥的位置

**Access Key ID + Secret Access Key**：
1. 登录火山引擎控制台
2. 进入"访问控制" → "密钥管理"
3. 创建或查看密钥对
4. ⚠️ Secret Key只在创建时显示一次！

**文生图 API Key**：
1. 登录火山引擎控制台
2. 进入"视觉智能" → "API密钥管理"
3. 创建API密钥
4. 复制密钥（单独的字符串）

## ⚠️ 常见问题

### Q1: 测试连接提示"火山引擎API密钥未配置"？

**A**: 请确保填写了3个密钥：
- ✅ Access Key ID
- ✅ Secret Access Key
- ✅ **文生图 API Key** ⭐ 新增的输入框

### Q2: 保存配置时报错"property xxx should not exist"？

**A**: 已修复！前端现在会自动过滤只读字段。

### Q3: 火山引擎有3个密钥太复杂了？

**A**: 这是火山引擎的设计：
- Access Key系统：通用服务
- API Key系统：文生图专用

91Writing的Provider会自动选择最佳认证方式：
- 如果配置了文生图API Key → 使用API Key认证（推荐）✅
- 如果只配置了Access Key → 降级使用签名认证

### Q4: 我只配置了Access Key和Secret Key，不配置文生图API Key可以吗？

**A**: 不可以。文生图API Key是必需的：
- 火山引擎文生图服务需要专用的API Key
- 只配置Access Key无法调用文生图API
- **必须配置3个密钥** ⚠️
