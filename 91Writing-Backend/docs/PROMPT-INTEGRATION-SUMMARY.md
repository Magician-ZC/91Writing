# 提示词集成总结

## 概述
本次更新将专业的角色抽取提示词和场景分镜提示词集成到了项目的 AI 服务中，优化了文生图和图生视频的提示词生成质量。

## 修改的文件

### 1. 角色抽取服务 (character-extraction.service.ts)

**修改位置**: `91Writing-Backend/apps/ai-service/src/services/character-extraction.service.ts`

**主要改进**:
- 集成了专业的角色形象创作大师提示词
- 添加了详细的风格词库参考（包括绘本风格、古风插画、日漫风格等15种风格）
- 添加了丰富的生图风格提示词参考（推文通用、新二次元、国风漫画等15种风格）
- 集成了完整的音色与情感库（32种音色配置）
- 增强了敏感信息过滤机制
- 优化了输出格式，添加了 voiceId、voiceSpeed、voiceDemo 等字段

**新增功能**:
- 角色形象描述要求100字以上，更加详细
- 整图纯白背景的专业要求
- 基于风格词库的综合设计
- 详细的角色配音配置（音色、语速、台词示例）

### 2. 分镜脚本生成服务 (storyboard-agent.service.ts)

**修改位置**: `91Writing-Backend/apps/ai-service/src/services/storyboard-agent.service.ts`

**主要改进**:
- 集成了专业短剧导演的分镜提示词系统
- 针对 seedream 生图模型和 seedance 生视频模型进行了优化
- 详细的分镜内容拆分规范：
  - `img_details`: 首帧图提示词（60字以上）
  - `video_details`: 视频动作提示词（100字以上）
  - `scriptLine`: 语音内容（15-40字）
  - `role_info`: 角色信息
  - `ref_img`: 参考图
- 添加了完整的风格词库（包含各类绘画、动画、影视风格）
- 集成了15种生图提示词参考模板
- 添加了音色和情感参考库（19种音色配置）

**新增功能**:
- 分镜数量至少20个的要求
- 前后分镜连贯性的重点关注
- 敏感信息自动检测和替换
- 详细的镜头描述规范（景别、时间、地点、环境、物体细节等）

### 3. 文生图优化服务 (image-generation-agent.service.ts)

**修改位置**: `91Writing-Backend/apps/ai-service/src/services/image-generation-agent.service.ts`

**主要改进**:
- 明确标注为 seedream 生图模型优化
- 详细的场景要素描述要求（景别、时间、地点、环境、物体细节等）
- 集成了完整的风格词库
- 添加了7种常用的生图提示词参考模板
- 优化了提示词生成流程，要求输出至少60字

**新增功能**:
- 景别描述（全景/中景/近景/特写）
- 物体细节的精确描述（形状/颜色/大小/位置）
- 角色站位、动作、表情的详细描述
- 敏感词汇自动检测和移除
- 输出改为中文描述，更加详细具体

### 4. 图生视频优化服务 (video-generation-agent.service.ts)

**修改位置**: `91Writing-Backend/apps/ai-service/src/services/video-generation-agent.service.ts`

**主要改进**:
- 明确标注为 seedance 生视频模型优化
- 详细的视频动作提示词要求（至少100字）
- 完整的运动描述规范：
  - 镜头运镜方式与变化
  - 角色站位/动作/表情
  - 说话人嘴部动作
  - 场景环境变化
  - 画面整体和细节变化
  - 风格描述

**新增功能**:
- 结合首帧图提示词进行画面动态过程描述
- 多个分镜间连贯性的重点考虑
- 画面主体位置和状态的明确要求
- 禁止使用指代词，确保描述具体
- 敏感词汇检测和移除
- 输出改为中文描述，至少100字

## 核心改进点

### 1. 风格词库统一
所有服务现在共享相同的风格词库，包括：
- 绘画风格（绘本、古风、lo-fi、宫崎骏、日漫、赛璐璐等）
- 动画/设计技术
- 影视风格/类型
- 摄影类型/风格
- 字体/文字设计
- 材质/工艺

### 2. 生图提示词参考库
统一的15种生图风格模板：
1. 推文通用
2. 新二次元
3. 二次元漫画
4. 二次元经典
5. 国风漫画
6. 都市气质
7. 现代都市
8. 2D古风
9. 仙侠古风
10. 仙侠古风2
11. 女频古风
12. 水墨国风
13. 国风水墨
14. 恐怖悬疑
15. 恐怖漫画

### 3. 音色配置库
完整的32种音色配置，包括：
- 多情感音色（14种，支持 happy/sad/angry/surprised/fear/hate/excited/coldness/neutral）
- 专业解说音色（6种，适合悬疑、科普、广告、影视解说等）
- 特色音色（12种，包括童声、动画角色、方言等）

### 4. 敏感信息过滤
所有服务都增强了敏感信息过滤机制，自动识别和替换：
- 涉政内容
- 涉黄内容
- 暴力、血腥内容
- 宗教、极端服饰
- 赌博、领导人、烈士陵园等

### 5. 输出规范统一
- 角色描述：整图纯白背景，100字以上
- 首帧图提示词：60字以上，包含景别、环境、物体细节
- 视频动作提示词：100字以上，详细描述运动过程
- 语音内容：15-40字，合适的音色和情感

## 技术细节

### seedream 生图模型优化
- 详细的景别描述
- 精确的物体细节（形状/颜色/大小/位置）
- 角色特征的一致性保证
- 风格标签的准确应用

### seedance 生视频模型优化
- 镜头运镜方式的详细描述
- 角色动作的连贯性
- 说话人嘴部动作的特别标注
- 场景环境变化的细致描述
- 前后分镜的效果连贯

## 使用建议

1. **角色创建**: 使用角色抽取服务时，确保提供详细的人物小传或剧本内容
2. **分镜生成**: 建议每集至少20个分镜，保持剧情连贯性
3. **图片生成**: 选择合适的风格词，确保角色一致性
4. **视频生成**: 注意前后分镜的运动连贯性，避免突兀的转场
