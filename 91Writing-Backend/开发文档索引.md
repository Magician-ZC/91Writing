## 🚀 快速开始

### 开发新的普通用户接口

```typescript
// 1. 创建DTO（3分钟）
export class CreateNovelDto {
  @ApiProperty({ description: '标题' })
  @IsString()
  @MinLength(1)
  @MaxLength(100)
  title: string;
}

// 2. 创建Controller（5分钟）
@ApiTags('novels')
@Controller()
@UseGuards(JwtAuthGuard)
@ApiBearerAuth('JWT-auth')
export class NovelController {
  @Post()
  @ApiOperation({ summary: '创建小说' })
  async create(@Request() req, @Body(ValidationPipe) dto: CreateNovelDto) {
    return this.service.create(req.user.id, dto);
  }
}

// 3. 创建Service（5分钟）
@Injectable()
export class NovelService {
  async create(userId: string, dto: CreateNovelDto) {
    return this.prisma.novel.create({
      data: { ...dto, userId }
    });
  }
}

// 4. 注册Module（2分钟）
@Module({
  imports: [DatabaseModule, JwtModule, PassportModule],
  controllers: [NovelController],
  providers: [NovelService, JwtStrategy],
})
export class NovelModule {}
```

**完整模板见**：[接口开发快速参考 - 快速开始模板](./接口开发快速参考.md#快速开始模板)

### 开发新的管理员接口

```typescript
// Controller（关键区别）
@ApiTags('管理员功能')
@Controller()
@UseGuards(AdminAuthGuard, RoleGuard)  // ⚠️ 使用管理员守卫
@ApiBearerAuth('JWT-auth')
export class AdminController {
  @Get('users')
  @Roles('ADMIN')  // ⚠️ 必须添加角色装饰器
  @ApiOperation({ summary: '获取用户列表' })
  async getUsers(@Query() query: QueryDto) {
    return this.service.getUsers(query);
  }
}
```

## ⚠️ 常见错误速查

| 错误 | 最可能原因 | 快速解决 |
|------|-----------|---------|
| **404** | Controller路径错误 | 微服务使用`@Controller()`不加前缀 |
| **401** | 缺少认证 | 添加`@UseGuards(JwtAuthGuard)` |
| **400** | DTO验证失败 | 检查验证装饰器和`@Type()`转换 |
| **403** | 权限不足 | 添加`@Roles('ADMIN')`装饰器 |

**详细排查**：[接口错误排查指南](./接口错误排查指南.md)

## 📋 开发检查清单

### 在提交代码前检查：

#### Controller检查
- [ ] 微服务Controller使用`@Controller()`不带前缀
- [ ] 添加了`@ApiTags()`
- [ ] 添加了认证Guards
- [ ] 所有方法有`@ApiOperation()`
- [ ] DELETE/POST非创建操作有`@HttpCode(HttpStatus.OK)`

#### DTO检查
- [ ] 所有字段有验证装饰器
- [ ] 必填字段用`@ApiProperty()`
- [ ] 可选字段用`@ApiPropertyOptional()`
- [ ] 数字类型有`@Type(() => Number)`
- [ ] 所有验证有错误消息

#### 认证检查
- [ ] 配置了JwtModule和PassportModule
- [ ] 实现了JwtStrategy
- [ ] Guard正确提取和验证token

#### 测试检查
- [ ] 服务能正常启动
- [ ] 无token访问返回401
- [ ] 有效token能正常访问
- [ ] 参数验证正常工作

**完整清单**：[接口开发规范文档 - 检查清单](./接口开发规范文档.md#检查清单)
