# 91Writing 微服务启动问题排查指南

## 🔍 问题诊断

您遇到的服务启动问题可能有以下几个原因：

### 1. 数据库连接问题
```bash
# 检查MySQL是否运行
docker-compose up -d mysql redis

# 测试数据库连接
npm run db:push
```

### 2. 端口冲突
```bash
# 检查端口占用
netstat -ano | findstr "3000 3001 3002 3003 3004"

# 释放被占用的端口
taskkill /f /pid <PID>
```

### 3. 环境变量问题
```bash
# 检查.env文件
Get-Content .env

# 确认包含以下变量：
DATABASE_URL=mysql://writing:writing123@localhost:3306/writing_platform
JWT_SECRET=91writing_jwt_secret_dev_2024
NODE_ENV=development
```

## 🚀 推荐启动顺序

### 方法一：单服务模式（推荐）
```bash
# 1. 只启动认证服务（包含邀请码功能）
cd 91Writing-Backend
npm run start:auth:dev

# 2. 在另一个终端启动前端
cd ..
npm run dev
```

### 方法二：完整微服务架构
```bash
# 1. 确保数据库运行
docker-compose up -d mysql redis

# 2. 构建项目
npm run build

# 3. 启动所有服务
npm run start:all
```
